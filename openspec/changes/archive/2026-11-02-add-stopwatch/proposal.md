# Proposal

## Why

Органайзер уже объединяет простые инструменты на одной стартовой странице. Секундомер — третий базовый инструмент, который логично добавить в тот же реестр, чтобы проверить, что архитектура расширяется без переделки существующих экранов.

## What Changes

- Добавляется новая страница секундомера с маршрутом `/stopwatch`.
- Секундомер показывает время в формате `мм:сс.сс` и управляется тремя кнопками: «Старт», «Стоп», «Сброс».
- «Старт» запускает отсчёт с нуля из состояния покоя и продолжает с сохранённого значения после паузы.
- «Стоп» ставит отсчёт на паузу, сохраняя значение.
- «Сброс» обнуляет значение и останавливает отсчёт из любого состояния.
- В реестр инструментов (`src/tools.js`) добавляется карточка «Секундомер», поэтому стартовая страница показывает три инструмента.
- Обновляется спецификация `tool-launcher`: перечень инструментов и сценарии переходов больше не ограничиваются двумя инструментами.

## Capabilities

### New Capabilities

- `stopwatch`: экран секундомера с отображением времени и управлением «Старт»/«Стоп»/«Сброс».

### Modified Capabilities

- `tool-launcher`: список инструментов на стартовой странице дополняется секундомером, добавляется сценарий перехода к нему.

## Impact

- Новый файл `src/pages/StopwatchPage.jsx`.
- Изменения в `src/tools.js` (новая запись) и `src/App.jsx` (новый маршрут).
- Новые стили в `src/styles.css` для дисплея и кнопок секундомера.
- Переиспользуется существующий `src/components/BackLink.jsx`.
- Новых зависимостей нет; состояние не сохраняется между сессиями и при уходе со страницы.
