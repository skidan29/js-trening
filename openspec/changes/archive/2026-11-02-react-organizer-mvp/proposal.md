# Proposal

## Why

Нужно небольшое React-приложение-органайзер, с которого пользователь за один клик попадает в нужный простой инструмент. Первая версия даёт минимальный MVP из трёх экранов, чтобы проверить структуру навигации и заложить основу для добавления новых инструментов.

## What Changes

- Создаётся новое SPA-приложение на Vite + React (JavaScript) с React Router.
- Добавляется стартовая страница со списком доступных инструментов (карточки «Часы» и «Калькулятор»).
- Добавляется страница цифровых часов с живым обновлением времени раз в секунду.
- Добавляется страница калькулятора с базовыми арифметическими операциями.
- Добавляется общий каркас навигации: переход на инструмент и возврат на стартовую страницу.
- Стилизация — обычный CSS без UI-библиотек.

## Capabilities

### New Capabilities

- `tool-launcher`: стартовая страница и навигация между инструментами органайзера.
- `clock`: экран цифровых часов с текущим временем.
- `calculator`: экран калькулятора с базовыми арифметическими операциями.
