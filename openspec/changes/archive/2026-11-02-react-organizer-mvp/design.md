# Design

## Context

Проект создаётся с нуля. См. `proposal.md` — мотивация и состав MVP. Ограничения: JavaScript (не TypeScript), обычный CSS без UI-библиотек, только браузер, без бэкенда и хранилища.

## Goals / Non-Goals

**Goals:**
- Три экрана с честными URL и навигацией браузера.
- Плоская и предсказуемая структура, которую легко расширить новым инструментом.
- Минимум зависимостей и конфигурации.

**Non-Goals:**
- Авторизация, сервер, сохранение данных между сессиями.
- Таймзоны, секундомер, история вычислений, научные функции.
- Тесты, CI, SSR, оптимизация производительности.

## Decisions

### Vite + React (JavaScript)
Vite даёт быстрый dev-сервер и минимальный boilerplate. JavaScript выбран по требованию пользователя; TypeScript отложен, пока приложение не вырастет.

### React Router (`react-router-dom`)
Три маршрута — `/`, `/clock`, `/calculator` — через `BrowserRouter` и `Routes`. Альтернатива «переключение по состоянию без роутера» отброшена: роутер бесплатно даёт URL, кнопку «назад» браузера и готов к росту числа инструментов.

### Реестр инструментов на стартовой странице
Стартовая страница рендерит карточки из массива `tools` (`{ id, title, path }`) в `src/tools.js`. Добавление инструмента = добавить элемент в массив и маршрут. Альтернатива — хардкод двух карточек — быстрее, но противоречит идее органайзера.

### Структура файлов
```
src/
  main.jsx
  App.jsx            # маршруты
  tools.js           # реестр инструментов
  components/
    BackLink.jsx     # общая кнопка "Назад"
  pages/
    HomePage.jsx
    ClockPage.jsx
    CalculatorPage.jsx
  styles.css         # общие стили
```

### Часы
Компонент хранит `Date` в состоянии, обновляет его через `setInterval` раз в секунду в `useEffect` и очищает интервал при размонтировании. Формат `чч:мм:сс` через `String(...).padStart(2, '0')`.

### Калькулятор
Состояние через `useState` (или `useReducer`): текущий ввод, предыдущий операнд, выбранная операция, флаг ожидания второго числа, сообщение об ошибке. Нажатие `=` вычисляет результат; деление на ноль переводит экран в состояние ошибки, `C` сбрасывает всё. Вычисления — обычные `Number`; округление результата не вводится, это осознанное упрощение MVP.

### Стили
Один общий `styles.css`: контейнер страницы, сетка карточек на старте, крупный дисплей часов и сетка кнопок калькулятора. Без CSS-фреймворков, чтобы не тянуть зависимости.

## Risks / Trade-offs

- `setInterval` может дрейфовать при throttling вкладки → для MVP допустимо; при необходимости позже перейти на пересчёт от `Date.now()`.
- Плавающая точка даёт `0.1 + 0.2 = 0.30000000000000004` → принято для MVP, без округления.
- `BrowserRouter` требует fallback на `index.html` при деплое → Vite dev-сервер уже это делает; для статического хостинга это надо будет настроить.
- Без тестов регрессии ловятся вручную → принято для MVP.

## Migration Plan

Greenfield: `npm install` и `npm run dev`. Данных для миграции нет, откат — удаление созданных файлов проекта.
