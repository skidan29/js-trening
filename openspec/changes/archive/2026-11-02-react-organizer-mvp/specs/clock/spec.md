# Spec Delta

## Purpose

Экран цифровых часов, показывающий текущее локальное время пользователя.

## ADDED Requirements

### Requirement: Отображение текущего времени

Страница часов SHALL отображать текущее локальное время в формате `чч:мм:сс` с двузначными числами часов, минут и секунд.

#### Scenario: Показ времени при открытии
- **WHEN** пользователь открывает страницу часов
- **THEN** он видит текущее локальное время в формате `чч:мм:сс`

### Requirement: Обновление времени

Отображаемое время SHALL обновляться не реже одного раза в секунду, чтобы соответствовать текущему времени.

#### Scenario: Смена секунды
- **WHEN** на странице часов проходит одна секунда
- **THEN** отображаемое значение секунд увеличивается на единицу (с переходом `59` -> `00`)

### Requirement: Возврат на стартовую страницу с часов

Страница часов SHALL содержать элемент навигации, возвращающий пользователя на стартовую страницу.

#### Scenario: Возврат со страницы часов
- **WHEN** пользователь на странице часов выбирает «Назад»
- **THEN** открывается стартовая страница (`/`)
