# Spec Delta

## Purpose

Стартовая страница органайзера, с которой пользователь выбирает нужный инструмент и переходит к нему.

## ADDED Requirements

### Requirement: Список доступных инструментов

Стартовая страница SHALL отображать карточки всех доступных в первой версии инструментов: «Часы» и «Калькулятор». Каждая карточка SHALL содержать название инструмента.

#### Scenario: Отображение инструментов на старте
- **WHEN** пользователь открывает стартовую страницу (`/`)
- **THEN** он видит карточки «Часы» и «Калькулятор»

### Requirement: Переход к инструменту

Выбор карточки на стартовой странице SHALL открывать страницу соответствующего инструмента.

#### Scenario: Переход к часам
- **WHEN** пользователь выбирает карточку «Часы»
- **THEN** открывается страница часов по маршруту `/clock`

#### Scenario: Переход к калькулятору
- **WHEN** пользователь выбирает карточку «Калькулятор»
- **THEN** открывается страница калькулятора по маршруту `/calculator`

### Requirement: Возврат на стартовую страницу

Каждая страница инструмента SHALL содержать элемент навигации, возвращающий пользователя на стартовую страницу.

#### Scenario: Возврат с помощью кнопки «Назад»
- **WHEN** пользователь находится на странице инструмента и выбирает «Назад»
- **THEN** открывается стартовая страница (`/`)
